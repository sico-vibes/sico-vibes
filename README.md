## 🛰️ About me

I'm an **AI-focused engineer and builder**. I started out in technical support at a telecoms company, saw where AI was taking desk jobs, and decided to get ahead of it by building. Now I ship at "AI speed": I orchestrate coding agents, CLIs, IDEs and APIs to deliver results fast, with smart prompts and low token use.

I love building my own stuff from scratch: internal tools, SaaS ideas, a Windows desktop app, and a few games on the side.

## ⚡ Focus areas

| | |
|---|---|
| 🧠 **AI orchestration** | Routing work across models, agents and CLIs, and carrying context between them |
| 📉 **Optimising AI usage** | Cheaper, faster, better results: free-tier-first, token-aware workflows |
| 🏢 **AI for business** | Bringing AI into real businesses safely, with guardrails |
| 🗂️ **AI data aggregation** | Pulling scattered AI and data sources into one place |
| 🖥️ **Windows desktop apps** | Native-feeling desktop companions for developers |
